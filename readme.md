# Web Shell

A single-file web shell built with PHP and JavaScript. It allows a user to execute system commands on the server via a simple, interactive browser interface.

---

## Warning

This tool executes arbitrary commands on the server and should never be deployed on live, production, or public-facing system. It is intended only for educational and controlled laboratory use. Deploying this script creates an extreme security vulnerability that can lead to the complete compromise of the host machine by any visitor.

---

## Ethical and Legal Notice

This tool is intended only for educational purposes and testing in your own lab or on systems for which you have explicit permission. Executing arbitrary commands on systems without authorization is unethical and illegal in virtually all jurisdictions. Do not use this tool on machines you do not own or have explicit permission to test.


---

## Features

- Stateless web shell
- Interactive terminal view
- Arbitrary command execution
- Command history

---

## Requirements

- PHP 5.2+
